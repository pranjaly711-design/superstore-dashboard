📊 Superstore Sales Dashboard | Power BI
🚀 Project Overview

This Power BI dashboard provides an interactive analysis of Superstore sales performance. It helps track key business metrics such as Sales, Profit, Quantity Sold, Discounts, Orders, Customer Segments, Categories, Regions, and Shipping Modes.

The dashboard enables users to identify profitable categories, regional performance, customer behavior, and sales trends over time.
